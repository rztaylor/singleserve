# Git Facts

- Default branch: `main`.
- Use feature branches and pull requests for repository-tracked changes.
- Keep commits focused and stage explanatory facts, specs, roadmap, changelog, and governance updates with their change.
- Preserve unrelated worktree content, including the existing `.agents/skills` symlink.
- Do not create a remote repository, push, open a PR, tag, publish, approve, or merge without explicit user direction.
- Use local Git for status, diff, branch, stage, and commit; use the configured GitHub connector for future hosted operations when authorized.
- Never move or overwrite a published tag.
